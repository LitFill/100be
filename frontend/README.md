# frontend

Static HTML page generated by [Koka](https://koka-lang.github.io) using a
type-safe HTML DSL (`frontend/html/`).

## Build

```sh
koka -e main.kk   # writes index.html
```

## Runtime Behavior

`index.html` serves as a SPA-style frontend for the URL shortener API (`localhost:8080`):

- **List** — fetches `GET /` on load, renders URL table
- **Create** — `POST /shorten` with `original-url` form field; optimistically
  prepends result to table
- **Delete** — `DELETE /:id` on button click; removes row client-side
- **Search** — Alpine.js `x-model` filter on short/long URL fields

### Stack

- [Pico CSS](https://picocss.com) (violet theme) — minimal classless framework
- [Alpine.js](https://alpinejs.dev) v3 — reactive DOM bindings
- static assets served from `/static/` (favicons, manifest)

## API Contract

Expects any backend implementing the contract below at `http://localhost:8080` with CORS.

| Method | Path       | Request Body         | Response             |
|--------|------------|----------------------|----------------------|
| GET    | /          | —                    | `[{short, long}]`    |
| POST   | /shorten   | `original-url=<url>` | `{short, long}`      |
| DELETE | /:id       | —                    | —                    |
